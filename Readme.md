# Contenify

Contenify is a web application that leverages AI to help users generate high-quality content effortlessly. Whether you need a blog post, an email template, or a creative story, Contenify has got you covered.

## Features

- **Blog Writer**: Craft engaging, SEO-friendly blog posts tailored to your audience.
- **Email Template Generator**: Generate polished, customized email templates for any occasion.
- **Story Writer**: Create original, captivating stories from simple prompts.

## Tech Stack

- **Frontend**: React, Tailwind CSS, Material Tailwind
- **Backend**: Node.js, Express, Sequelize, MySQL
- **AI Integration**: Google Generative AI
